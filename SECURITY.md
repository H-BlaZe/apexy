# Security policy

## Supported versions

Only the [latest release](https://github.com/H-BlaZe/Apexy/releases/latest) gets fixes.

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately through [GitHub Security Advisories](https://github.com/H-BlaZe/Apexy/security/advisories/new).

Include:
- what the problem is and what an attacker could do with it
- steps to reproduce, and the Apexy version and Android version
- a proof of concept, if you have one

You'll get a reply within 7 days. Once a fix is released you'll be credited, unless you'd rather not be.

## Scope

Apexy has no internet permission and no server, so most issues will involve local data (backups, recordings, the database), exported components, or permissions. A report showing the app can reach the network in any way is treated as critical.
